FAQ

Les quatre questions utiles.

Mes fichiers sont-ils envoyés sur Internet ?

Non pour les traitements locaux de FileFlow : vos fichiers sont traités sur votre machine.

Pourquoi macOS peut-il afficher un avertissement ?

FileFlow est distribué gratuitement hors du Mac App Store et n’est pas notarifié par Apple. Le guide macOS montre la première ouverture.

Quels systèmes sont compatibles ?

macOS Apple Silicon et Intel, Windows x64, Linux x64 et Linux ARM64.

Comment réparer ou désinstaller FileFlow ?

Relancez FileFlow Setup : il propose diagnostic, réparation et désinstallation propre.
